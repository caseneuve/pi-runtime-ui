## Context

Six remaining diagnostics are confined to tests: four `ExtensionUIContext`
fixture assertions in external-editor tests and two assertions after parsing
packed/project manifests. Replace them with precise fixtures and a small
explicit JSON test boundary without weakening coverage.

## Acceptance Criteria

- [ ] External-editor tests construct the smallest accurately typed UI fixture
      or helper needed by the production API; remove broad assertions and do not
      add module mocks or `never` escape hatches.
- [ ] Package tests parse JSON through a named test-domain decoder or focused
      guard before accessing manifest fields; parsed values do not propagate as
      `unknown`.
- [ ] Existing assertions about editor behavior and manifest/resource metadata
      remain equally strong or become stronger; `npm run pack:check` continues
      to verify packed contents.
- [ ] All six owned assertion diagnostics disappear with no new anti-slop
      diagnostic identity in modified tests.
- [ ] `npm run check:ci`, `npm run typecheck`, focused tests,
      `npm run test:coverage`, and `npm run pack:check` pass.
- [ ] Independent review approves this subtask against `AGENTS.md`.

## Affected Files

- `test/external-editor.test.ts` — four UI fixture assertions.
- `test/package.test.ts` — two parsed-JSON assertions and any focused decoder.

## Notes

- Prefer a reusable precise fixture only if it removes duplication; do not add a
  test abstraction larger than the assertions it replaces.
- This is test-only and has no visible UI change, so screenshot review is not
  required.
