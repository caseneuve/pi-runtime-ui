explicit-name presentation and generic editor status readers are future tasks;
this task does not alter that producer or share footer provider state.

setWorkingStatusIndicator method (type derived from exported CustomEditor), while
continuing to call the base implementation. Reserve Git space only if the current

private fields, or recreate lifecycle state. All indicators keep native rendering.
